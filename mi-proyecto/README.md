# Api `mi-proyecto` from `Express`

Boilerplate for a simple express project with runtime environments and error handling.

## Requirements
Node.js 20 or higher
npm, pnpm, or yarn

## Installation

### Install the project dependencies:

```bash

npm install

```

### Create the environment variables file from the example:

cp .env.example .env

Configure the necessary variables before starting the server.

Este proyecto cuenta con orm sequelize  y con una carpeta de archivos fuente de nombre src
